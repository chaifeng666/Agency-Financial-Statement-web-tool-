決算書表套版工具

系統產製 .xls ＋ 以往年度定稿格式 → 新年度決算書表（單機作業，資料不離開本機）
  1. 1載入檔案範本＋系統產製檔
  2. 2表名對照確認每張表的來源
  3. 3內容核對18 條表間勾稽
  4. 4缺檔表處理#12 判斷、#38 推算
  5. 5產生報表套格式、下載
  6. 6對外公告檔XML／MD，每表一檔
  7. 7格式 1～5封面、目次、總說明…

步驟一　載入檔案

選擇「以往年度定稿」當格式範本，再選本年度系統產製的全部 .xls（系統下載的 .7z 請先解壓縮）。

① 範本（以往年度定稿 .xlsx）

例：112年度決算書表_v1.xlsx

② 本年度系統產製檔（.xls，可多選）

檔名格式：114_表號_表名_時間.xls。也可直接拖曳整個資料夾的檔案進來。
    兩項都載入後才能繼續

    步驟二　表名對照

    依檔名中的表號自動對應範本工作表。請確認每一列的處理方式。

    表號表名範本工作表本年度系統檔處理方式

    步驟三　內容核對

    檢查各表之間應該相等的數字。點任一規則可展開比對明細。不符時仍可繼續，但結果會寫進輸出檔的「核對結果」工作表備查。

    步驟四　缺檔表處理

    系統沒有產製的兩張表：#12 依 #4 判斷有無；#38 依各表數字推算，請核對並補上無法自動取得的數字。

    #12 歲出賸餘（或減免、註銷）分析表

    #38 決算與會計收支對照表

    預算項目決算數調整數會計收支會計科目

    步驟五　產生報表

    內容、列數、合併儲存格照系統檔；欄寬、字型、框線、列印設定、頁首頁尾照範本，年度字樣自動更新。

    步驟六　產製對外公告檔

    用同一份已核對的數字，每張表產出一個 XML（英文標籤，給系統讀）和一個 MD（給網站公告、人看）。打包成 zip，附目錄與每個檔案的 SHA-256 雜湊值。

    依「中央政府決算書表之格式」格式 1～5。數字從已載入的系統檔自動帶入，文字請在下方填寫；右邊即時預覽。每個格式看過沒問題請按「確認此格式」，5 個都確認後才能下載。
    
      
    
        
        
        
        
      
    
      
    
      
    
        
    
        
    
          
    
          
    
        
    
      
    
      
    
        
        
        
        
        
      
    
    
    

  
    

    



    
  
    決算書表編製標準作業流程
    
  
    每年決算時依序辦理；每個步驟完成都要在工具裡按「確認」，確認時間會留在輸出檔「核對結果」工作表。
    

  
    一、事前準備
    
  
      
    
    1. 從會計系統下載本年度決算書表（各表 .xls，或系統打包的 .7z），.7z 先解壓縮。
      2. 
    
    2. 取得「前一年度」或最近一年的決算書表定稿 .xlsx，當作格式範本（定稿以後不要再改結構）。
      3. 
    
    3. 確認檔名開頭是年度與表號，例如 114_2_決算編制_歲出政事別決算表_…xls；檔名被改掉會對不到表。
      4. 
  
    

  
    二、表名對照（工具步驟二）
    
  
      
    
    1. 工具依表號自動對應範本工作表。
      2. 
    
    2. 逐列確認狀態：系統檔 直接套用；固定頁（10-1 本頁空白、19 廣宣另行 PDF）照抄；推算（#38）；判斷（#12）；缺檔 要回系統補下載。
      3. 
    
    3. 平衡表各科目明細表（22～36）：只輸出有系統檔的科目，工具用明細表總計金額對到平衡表科目。
      4. 
  
    

  
    三、內容核對（工具步驟三，18 條）
    
  
      
    
    • 歲入：A1 歲入實現數＝繳付公庫數（#1、#8、#21、#39）；A2 #1 各款＝#21 收入科目；A3 #10 餘絀數＝#1 比較增減數。
      • 
    
    • 歲出：B1 #2＝#3 合計；B2 #9 實現數、未撥入數＝#2、#11；B3 #6 合計＝#3 扣除統籌科目；B4 以前年度實現數 #4＝#9＝#39；B5 #13 人事費＝#6；B6 #18 千元總計≒#2；B7 #4 減免（註銷）數判斷 #12。
      • 
    
    • 財務：C1 平衡表兩邊相等；C2 公庫撥入數 #9＝#21＝#39；C3 專戶存款＝現金出納表結存；C4 #37 期末帳面＝#20 成本減累計折舊；C5 #40 總值＝#37；C6 收支餘絀＝收入－支出；C7 淨資產增減＝收支餘絀＋其他影響項目；C8 財產損失、折舊、明細表與 #20 一致。
      • 
    
    • 有紅燈時：先回系統查原因（多半是匯出時間不同、補登傳票後沒有重新匯出），修正後重新下載再跑一次。真的確認無誤才繼續，並在核對結果工作表註記原因。
      • 
  
    

  
    四、缺檔表處理（工具步驟四）
    
  
      
    
    1. #12：#4「本年度減免（註銷）數」為 0 就輸出「本年度無」；不為 0 要依 #4 人工編製。
      2. 
    
    2. #38：決算數取 #1、#6（人事費含統籌科目），會計收支取 #21，調整數＝會計收支－決算數。
      3. 
    
    3. 業務費調整數＝未達財產標準數－本年度申請保留數（#11 經常門）＋本年度支付以前年度保留數（#39）。未達財產標準數請以帳上數字填入，工具會驗算是否兜得攏。
      4. 
    
    4. 核對備註文字，必要時直接修改。
      5. 
  
    

  
    五、產生與覆核（工具步驟五）
    
  
      
    
    1. 產生 .xlsx 後用 Excel 開啟，逐表列印預覽：分頁、起始頁碼、頁首頁尾年度。
      2. 
    
    2. 人工複核文字欄：#6 備註、#10 原因說明、#11 保留原因、#13 說明、#16 委辦備註、#17 出國備註。
      3. 
    
    3. 範本中由人工加的額外文字（例如合計列下方的說明）不會自動帶入，請比對前一年補上。
      4. 
    
    4. 覆核完成後另存為「○○年度決算書表定稿.xlsx」，當作下一年度的範本。
      5. 
  
    

  
    六、對外公告檔（工具步驟六）
    
  
      
    
    1. 勾選要公告的表（預設全部有數字的表；10-1 本頁空白、19 廣宣不產）。
      2. 
    
    2. #17 出國人員姓名預設遮蔽（王○明），職稱保留。
      3. 
    
    3. 下載 zip：每張表一個 XML（英文標籤、原始數字、附欄位中文說明）和一個 MD（千分位、合計列粗體）。
      4. 
    
    4. 上網公告前，用 index.md 裡的 SHA-256 雜湊值核對檔案沒有被改動（Windows：certutil -hashfile 檔名 SHA256）。
      5. 
    
    5. 公告檔用的是步驟五同一份數字；如果步驟五之後有人工修改 Excel 定稿，公告檔不會跟著變，請改完重新跑一次。
      6. 
  
    

  
    七、格式 1～5（工具步驟七）
    
  
      
    
    1. 依行政院主計總處「中央政府決算書表之格式」：格式 1 封面、2 封底、3 目次、4 總說明、5 歲入來源別決算表。
      2. 
    
    2. 自動帶入：年度、期間、款項號（#3）、歲入歲出與以前年度執行數（#1、#3、#5）、平衡表重要科目及變動達 5 億元或 20% 以上之科目（#20）、格式 5 全表（#1）。
      3. 
    
    3. 人工填寫：封底職名、目次分類與各表頁數（起始頁自動累計）、總說明各段原因說明、或有給付責任、施政計畫分項。
      4. 
    
    4. 每個格式預覽無誤按「確認此格式」，5 個都確認才可下載；確認後再修改會自動取消確認。
      5. 
    
    5. 年底完成後「匯出設定檔」保存，明年「匯入設定檔」即可沿用封面、封底、目次分類、施政計畫項目；上年度或有給付責任金額會自動移到「上年」欄。
      6. 
  
    

  
    八、權責分工建議
    
  
      
    
    • 承辦人：步驟一～五，紅燈先查明原因。
      • 
    
    • 複核人：看「核對結果」工作表與列印預覽，抽查 #2、#20、#21、#38 數字。
      •
