決算書表編製工具　整合版

系統產製 .xls ＋ 以往年度定稿（PDF 或 .xlsx）→ 編修、核對 → Excel／列印版面／公告檔／格式 1～5（單機作業，資料不離開本機）
  1. 1載入檔案系統檔＋範本 PDF／xlsx
  2. 2表名對照來源與範本頁次
  3. 3格式說明檢視與編修各表版面
  4. 4編修內容系統值可改，合計自動重算
  5. 5內容核對18 條勾稽（用編修後數字）
  6. 6#12、#38判斷與推算
  7. 7產出Excel、列印版面、公告檔
  8. 8格式 1～5封面、目次…（MD）

步驟一　載入檔案

載入本年度系統產製檔，只處理有上傳的書表；沒有上傳的表不會出現在後面的步驟。格式用內建的 113 年度規格，也可以匯入去年匯出的規格檔。

系統產製檔提供數字。範本可擇一或兩者都載入：PDF 提供列印版面格式、總說明與立法院決議辦理情形文字；.xlsx 提供 Excel 套版格式。都不載入時，格式用內建的 113 年度規格。

① 本年度系統產製檔（.xls，可多選）必要

檔名格式：114_表號_表名_時間.xls。系統下載的 .7z 請先解壓縮。

② 範本：以往年度決算書 PDF選用

例：113年度單位決算.pdf。工具會辨認每頁屬於哪張表，並擷取總說明與 #41 文字供編修。

③ 範本：以往年度定稿 .xlsx選用

例：112年度決算書表.xlsx。載入後步驟七可另外產出「套用此範本格式」的 Excel（沿用範本的欄寬、字型、框線、列印設定與頁首頁尾，年度字樣自動更新）。
    格式規格檔（選用）
    請先載入系統產製檔

    步驟二　表名對照

    依規格逐表列出來源：系統檔 數字取自系統產製檔、手填 在步驟四輸入、推算 在步驟六自動計算、文字 為總說明。範本頁次取自 PDF 辨識結果。

    表號表名來源本年度系統檔範本頁次範本工作表（xlsx）

    步驟三　各表格式（可編修）

    只列出有上傳系統檔的書表。點左邊任一張表，右邊可修改：對頁／單頁、標題文字與拆法、各欄寬度（mm）、字級、手填表的表頭；下方即時預覽本年度版面。改過的格式會用在列印版面與「依格式規格」的 Excel；可匯出規格檔，明年在步驟一匯入沿用。

    表號表名／版面
    點左邊的表開始檢視或修改格式。

    步驟四　編修各表內容

    數字預設為系統產製值，可以直接修改；合計、小計、比較增減、比率等由工具依系統檔的計算關係自動重算（灰底不可改）。修改過的格子是黃底，滑鼠移上去可看系統原值。

      步驟五　內容核對

      用編修後的數字檢查各表之間應該相等的數字。不符時可回步驟四修改，或查明原因後繼續（會記在 Excel 的「核對結果」工作表）。

      步驟六　#12 判斷與 #38 推算

      #12 歲出賸餘（或減免、註銷）分析表

      #38 決算與會計收支對照表

      預算項目決算數調整數會計收支會計科目

      步驟七　產出

      全部用步驟四編修後、步驟五核對過的同一份數字。

      決算書表編製標準作業流程（簡易版）
      
  
      只處理有上傳的系統產製書表；沒有上傳的表不進入後續程序。
      
  
        
    
      1. 載入：選本年度系統產製的 .xls（檔名不要改，.7z 先解壓縮）。可匯入去年匯出的規格檔沿用格式。
        2. 
    
      2. 表名對照：確認哪些表有上傳；未上傳的表本次不處理。
        3. 
    
      3. 格式：逐表檢視並修改對頁／單頁、標題、欄寬、字級，看預覽確認；完成後「匯出規格檔」留給明年。
        4. 
    
      4. 編修內容：系統值原則上不改；確需調整只改明細，合計與比率自動重算，修改紀錄寫入 Excel。
        5. 
    
      5. 產出：產生列印版面（可列印／存 PDF）與 Excel，逐頁檢視分頁與頁碼。
        6. 
  
      
  
      需要總說明、#12、#19、#38、#41、表間勾稽、公告檔或格式 1～5 時，請改用完整版（index.html）。
      

      

      
  
      決算書表編製標準作業流程
      
  
      數字一律以系統產製檔為準，需要調整時在工具內編修並留下紀錄。範本有兩種，可擇一或並用：以往年度定稿 PDF（列印版面、總說明與 #41 文字）、以往年度定稿 .xlsx（Excel 套版）。
      
  
      範本怎麼選
      
  
        
    
      • 只有定稿 PDF：用「依格式規格」產出 Excel 與列印版面（建議作法）。
        • 
    
      • 只有定稿 .xlsx：Excel 選「套用範本 .xlsx 格式」，列印版面用內建規格；總說明、#41 從空白開始。
        • 
    
      • 兩者都有：兩種 Excel 都可產出，列印版面依 PDF。套範本 .xlsx 的 Excel 中，沒有系統檔的表（#19、#41、總說明等）沿用範本內容，請以列印版面或依規格的 Excel 為準。
        • 
  
      
  
      一、事前準備
      
  
        
    
      1. 從會計系統下載本年度各表 .xls（.7z 先解壓縮），檔名不要改。
        2. 
    
      2. 準備前一年度決算書定稿 PDF（例：113 年度），作為格式與文字範本。
        3. 
    
      3. 如有前一年匯出的「規格檔」或「編修檔」一併備妥。
        4. 
  
      
  
      二、載入與對照（步驟一、二）
      
  
        
    
      1. 載入系統檔與範本 PDF，確認機關名稱。工具會辨認 PDF 每頁屬於哪張表（頁首標題比對）。
        2. 
    
      2. 逐列確認來源：系統檔、手填（#12、#19、#41、無系統檔的科目明細表）、推算（#38）、文字（總說明）。
        3. 
  
      
  
      三、格式說明（步驟三）
      
  
        
    
      1. 檢視每張表的版面：對頁表左頁標題靠右、右頁標題靠左；欄寬依範本 PDF 量測（mm）；標題、表頭用標楷體，內文新細明體 10 點。
        2. 
    
      2. 點表預覽第一頁，確認欄位沒有被截斷。需要調整時改規格檔後重新匯入。
        3. 
    
      3. 下載「格式說明」存檔備查。
        4. 
  
      
  
      四、編修內容（步驟四）
      
  
        
    
      1. 系統值原則上不改；確需調整（例如系統產製後補登傳票）時，只改明細數字，合計與比率由工具重算。
        2. 
    
      2. 總說明：工具依本年度數字套用範本句型產生草稿，標示「（請填原因）」處必須補寫；施政計畫分項說明沿用範本後修正。
        3. 
    
      3. #41 立法院決議辦理情形：沿用範本內容，逐項更新辦理情形。
        4. 
    
      4. #19 媒體政策及業務宣導經費：依實際資料填列，合計、比較增減與百分比自動計算。
        5. 
    
      5. 做到一半可「匯出編修檔」，下次「匯入編修檔」接續。
        6. 
  
      
  
      五、核對、推算（步驟五、六）
      
  
        
    
      • 18 條勾稽以編修後數字檢查；紅燈先查原因，必要時回步驟四修改。
        • 
    
      • #12 依 #4 減免（註銷）數判斷；#38 依各表推算，未達財產標準數以帳上數字為準。
        • 
  
      
  
      六、產出與覆核（步驟七、八）
      
  
        
    
      1. 列印版面：產生後到「列印版面」分頁逐頁檢視，確認分頁、對頁、本頁空白與頁碼；按「列印／存 PDF」（A4、邊界「無」、勾選背景圖形）。下載的 .html 之後可用「開啟已存的列印版面檔」再列印。
        2. 
    
      2. Excel：每表一個工作表，附「核對結果」（勾稽、確認時間、編修紀錄）供複核人查核。
        3. 
    
      3. 公告檔：每表 XML＋MD 與 SHA-256 雜湊；#17 姓名預設遮蔽。
        4. 
    
      4. 格式 1～5 依「中央政府決算書表之格式」產生 MD，逐一確認。
        5. 
    
      5. 完成後匯出規格檔與編修檔，連同定稿 PDF 留作下一年度範本。
        6.
