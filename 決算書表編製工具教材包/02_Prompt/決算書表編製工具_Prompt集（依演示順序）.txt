決算書表編製工具　Prompt 集（依演示順序）
主計 AI 應用與實作課程｜案例：決算書表編製工具

【使用說明】
1. 依 STEP 0 → STEP 9 的順序（STEP 5 分為 5-1～5-7），把「▼ 請複製以下 Prompt ▼」到「▲ Prompt 結束 ▲」之間的文字貼給 AI。
2. 適用工具：可上傳檔案、可產生檔案的 AI 對話工具（例如 Claude）。〔 〕內換成自己的資料。
3. 素材來源為公開決算書表，教學示範用；出國人員、明細表中的人名已虛構或遮蔽。
4. 注意資安與個資：只上傳已去識別的資料；機關正式資料請在單機工具內處理，不要上傳到網路服務。
5. 標 ★ 的步驟若卡關，改用「05_★半成品與題目檔」的半成品接續。
6. AI 產出的數字與文字都要人工複核，以系統產製檔為準。
7. 各流程「一定要用到的提示語」與工具 UI 操作畫面的對照，請看同資料夾的「決算書表編製工具_各流程必用提示語與UI操作對照.docx」。

============================================================
【STEP 0】角色設定與工作規範
------------------------------------------------------------
目的：讓 AI 先知道身分、規範與工作方式，避免猜測或一次做錯整套。
上傳素材：無
▼ 請複製以下 Prompt ▼
你是熟悉中央政府決算書表格式與會計作業的資訊助理，我是〔機關〕的主計人員。請遵守：
1. 不可猜測：檔案看不清楚或資料不足時，直接說明並請我補充。
2. 無法辨識的表號、欄位或數字，要標註「無法辨識」並列出位置。
3. 格式統一：金額千分位、比率小數 2 位、表號用「#數字」。
4. 主動標註疑義：表與表之間數字對不上、或與以往年度差異大，要主動提出。
5. 每個步驟完成後先條列結果，等我確認才進行下一步；有兩種以上做法時用選項讓我選。
6. 產出的工具必須是單一 HTML 檔、離線執行、資料不離開本機，且不使用中國大陸開發的元件，並附元件清單（SBOM）。
7. 系統產製的數字一律為準；任何人工修改都要留下紀錄。
▲ Prompt 結束 ▲
預期結果：AI 回覆「了解」並複述 7 項規範，等待上傳檔案。
卡關時怎麼辦：若 AI 直接開始產出，回覆「請先等我上傳檔案，並每步確認」。
對應 UI 畫面：02_Prompt／UI操作畫面／ui11_元件清單.png（紅框數字＝操作順序）

【STEP 5】★ 從零生成 HTML 工具（5-1～5-7，給沒有寫過程式的主計人員）
------------------------------------------------------------
目的：不用自己寫程式，依序貼 5-1～5-6 的提示詞，請 AI 從系統產製檔出發、參考範本檔（Excel 或 PDF 皆可）調整各書表格式，做成單一 HTML 工具。5-7 簡易版為選用。
新手須知：
・存檔：AI 給檔案就直接下載；只給程式碼文字時：全選複製 → 記事本貼上 → 另存新檔，檔名用 .html、編碼選 UTF-8。
・開啟：雙擊 .html，用 Chrome 或 Edge 開，不用安裝。
・版次：每次修改另存 v1、v2、v3，不要覆蓋，改壞可以退回。
・報錯：畫面有紅字或按了沒反應，按 F12 →「Console」分頁截圖給 AI。
・範本：Excel 或 PDF 都可以；有 Excel 範本時，Excel 產出最接近原格式。
・資料：練習用教材素材；機關正式資料不上傳 AI，在完成的工具內處理。
・對話太長、AI 開始忘記規則時：開新對話，先貼 STEP 0，再上傳最新版 .html 與規格檔，說明「接續修改」。

限制：
1. 只做一個 .html 檔，用 Chrome／Edge 雙擊就能開，不用安裝、不用連網。
2. 用到的程式元件全部內嵌在檔案裡，不可使用中國大陸開發的元件；列出元件清單（名稱、版本、來源、授權、開發者國別）。
3. 資料只在本機瀏覽器處理，不上傳任何地方。
4. 介面用繁體中文，一步一步操作，每步有「確認，下一步」按鈕。
請先不要寫程式。先條列回覆：(1) 工作流程圖（每一步做什麼）；(2) 每個畫面的按鈕與欄位；(3) 你需要我提供哪些檔案。等我確認後再開始。
▲ Prompt 結束 ▲
需要與我確認：工作流程圖：載入→表名對照→格式編修→預覽→產出、每個畫面的按鈕與欄位、需要提供哪些檔案、元件清單：無中國大陸元件

卡關時怎麼辦：AI 若直接給程式碼，回覆「請先停，先給我流程圖確認」。
