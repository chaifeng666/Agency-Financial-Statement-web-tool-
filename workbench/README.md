# 決算書表工作台

主計人員編製年度單位決算用的網頁工具。上方選單：

1. **作業流程圖**：依專案資料夾架構的七個階段（蒐集原始資料 → 整理調整 → 產製書表 → 勾稽檢核 → 複核簽核 → 輸出送審 → 歸檔），點選看工作項目與檢核重點。
2. **生成總說明**：讀取會計系統產製的決算書表（表 1、3、5、8、9、11、20、37），依編製要點格式 4 產生總說明，自動勾稽表與表之間的數字，可切換顯示〔表號 儲存格〕數據來源，下載 Word。
3. **生成目次**：依 114 年度用印版目次排列，輸入頁數自動編頁碼（跨頁表件自偶數頁起），下載 Word。
4. **各書表格式調整**：把系統產製 .xls 整理成可列印的 Excel（補表頭、標楷體、千分位、百分比、A4、每頁重複標題列、頁碼），可單張或整批 zip 下載。

## 使用方式

- 直接用瀏覽器開啟 `index.html`（不需安裝、不需網路；`vendor/` 內含所需程式庫）。
- 點「載入系統產製書表」，選取 `02_原始資料\系統產製書表\{年度}年系統產製\` 內的全部 .xls。檔名需保留系統格式 `{年度}_{表號}_…`。
- **所有檔案只在瀏覽器內處理，不會上傳到任何伺服器**；本儲存庫不含任何機關資料。

## 注意

- 紅字【待補】為系統書表沒有的資料（施政成果、平衡表變動原因、未來或有給付責任），須人工撰寫。
- 科目內容說明文字預設沿用上年度（行政院主計總處），其他機關請改寫。
- 114 年度實測：總說明第一、二節 121 個數字與 114 年度用印版相符；目次頁碼與用印版一致。
