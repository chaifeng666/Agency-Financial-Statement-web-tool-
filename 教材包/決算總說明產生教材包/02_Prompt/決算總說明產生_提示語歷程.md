# 決算總說明產生　提示語歷程

主計 AI 應用與實作課程｜案例：決算總說明產生｜講師：家鳳

這份文件記錄實際操作時一路下過的 4 則指令、AI 做了什麼、學到什麼，最後整理成可以照順序貼上的提示語鏈（即 Prompt 集 STEP 0～7）。

---

## 一、實際歷程（原始指令照錄）

| 則 | 原始指令 | 上傳／連結的檔案 | AI 做了什麼 | 產出 |
|---|---|---|---|---|
| 1 | 「取出總說明，生成總說明的數據，參考書表的表名及位置」 | 113 年度決算書 PDF（215 頁） | 讀目次找到總說明在 PDF 第 5～25 頁；取出一、二段 105 個數字，逐一到書表頁找來源；固定資產改用淨額驗算；用公式組出總說明文句 | 113年度總說明數據對照.xlsx（105 項全部相符） |
| 2 | 「參考上傳檔案內容，各產生 114 年度總說明，另含數字來源的說明，2 份 word；最後使用一個 html 下載」 | 114 年系統產製資料夾（15 個 .xls） | 依第 1 則的規則從 .xls 取數；保留原因從保留分析表摘要；書表沒有的文字用黃底紅字標出；2 份 Word 內嵌進 1 個 HTML | 114年度總說明.docx、114年度總說明_數字來源說明.docx、114年度總說明下載.html |
| 3 | 「彙成本次流程，包含上傳檔案，找出總說明參考書表位置，可以匯入某年度的系統產製表件；生成新年度的總說明的 word；做成互動式網頁，使用落地版本，不使用大陸元件」 | 同上 | 做成 5 步驟的單一 HTML 工具；SheetJS 0.20.3、PDF.js 3.11.174 內嵌；Word 自行組成；用 113 PDF 與 114 .xls 實測並修正 3 個問題 | 總說明產生工具.html |
| 4 | 「彙整所有提示詞，做成教材包，並上載到 github 上」 | 既有教材包（取簡報模板與格式） | 整理本文件與 Prompt 集、簡報、題目檔、半成品，上傳 GitHub | 本教材包 |

### 啟示
1. **一句話也能開始，但條件要補齊**：第 1 則只有一句話，AI 自行決定了輸出格式（Excel）。整理後的 STEP 1 把「要哪些欄位、哪些工作表」講清楚，結果更穩定。
2. **先建立「數字 → 書表位置」對照，再談自動化**：有了第 1 則的對照表，第 2 則才能照規則產生新年度，第 3 則才能寫成工具。
3. **書表沒有的文字不要讓 AI 編**：動支第一預備金用途、施政成果都不在系統檔裡，要求 AI 用黃底紅字標出待補。
4. **元件要指定版本與國別**：「落地版本、不使用大陸元件」要寫成「單一 HTML、元件內嵌、附元件清單（SBOM）」，AI 才會照做並交代來源。
5. **測試要用真檔案**：工具第一版有 3 個問題（平衡表左右欄混讀、預備金動支重複列、步驟區塊沒隱藏），都是用實際檔案測出來的。

## 二、整理後的提示語鏈

照順序貼上即可重建本案例全部成果；完整版（含預期結果、卡關處理）見「決算總說明產生_Prompt集（依演示順序）.txt」。

| STEP | 名稱 | 要點 |
|---|---|---|
| 0 | 角色與規範 | 不猜測、標註無法辨識、格式統一、主動標疑義、數字可追溯、書表沒有的不編、單一 HTML 無大陸元件 |
| 1 | 取出總說明＋書表位置 | 目次→頁碼差；數字逐一對書表（表名、頁、列×欄）；計算值寫算式；20% 變動；產生 Excel |
| 2 | 歸納句型與取數規則 | 段落→書表→列欄→算法；句型變化條件；人工補充 4 類；先確認不產檔 |
| 3 | ★產生新年度總說明 | 2 份 Word（總說明、數字來源說明）＋1 個下載 HTML；黃底紅字待補 |
| 4-1 | 工具需求與流程圖 | 5 個步驟；限制條件；先給流程圖與元件清單 |
| 4-2 | ★生成工具 | 指定元件版本；用科目編號找列；表間檢核；實測後再交檔 |
| 4-3 | 測試與修正 | 一句話＋截圖，每次一件 |
| 5 | 工具內操作 | PDF→系統檔→檢核→補文字→下載 |
| 6 | 定稿與複核 | 逐段檢查，只列問題 |
| 7 | 教材包與 GitHub | 5 項教材、模板、STEP by STEP、上傳 |

## 三、驗收清單

- [ ] 總說明每個數字都能在「數字來源說明」找到來源檔、儲存格、列 × 欄
- [ ] 表間檢核全部相符（114 年度 26 項）
- [ ] 比率＝(實現＋保留)÷預算×100，小數 2 位；100 寫「100%」
- [ ] 平衡表變動達 20% 的科目都有原因說明
- [ ] 保留原因的轉入年度是「下一年度」
- [ ] 黃底紅字全部補完並刪除標示
- [ ] 工具為單一 HTML、可離線開啟、元件清單無中國大陸元件

## 四、新手須知

- **存檔**：AI 給檔案就直接下載；只給程式碼文字時，全選複製→記事本貼上→另存為「.html」，編碼選 UTF-8。
- **開啟**：用 Chrome 或 Edge 雙擊 .html；不需要安裝、不需要網路。
- **版本**：每次修改後檔名加日期或版次，例如「總說明產生工具_v2.html」，有問題可退回上一版。
- **對話太長**：AI 開始忘記規則時，開新對話，先貼 STEP 0，再上傳最新版檔案。
